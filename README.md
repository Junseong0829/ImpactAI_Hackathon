## 📝 소개
**⚖️ 균형을 묻다, 아고라** 는 에코 체임버 현상을 해결하기 위해 고안된 AI 기반 뉴스 기사 사이트입니다.

진보, 중립, 보수 총 3가지 영역의 언론사에서 생성된 다양한 기사들을 종합해서 사용자에게 보여줍니다.

아래와 같은 기능을 제공합니다.
- Home : 메인 뉴스 토픽 제공 및 좌/우 성향별 인원 수, AI 토론 이용자 수를 보여줍니다.
- Article : Left, Center, Right 총 3가지 영역의 기사를 제공합니다.
- Chat : 여러 기사를 기반으로 학습된 AI와 뉴스 주제에 대해 토론할 수 있습니다.
- Login / MyPage : 얼마나 AI와 토론을 진행했는 지, 나의 편향 정도는 어느 정도인 지 확인할 수 있습니다.
